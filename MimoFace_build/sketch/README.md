# Mimo Face — ESP32-S3 / 240×320

## پروژه
صورت میمو بدون قاب، جوانه و گونه‌ها: فقط چشم، ابرو و دهان.
چشم‌ها به‌آرامی نگاه عوض می‌کنند و خودکار پلک می‌زنند.
صورت با منحنی‌های برداری رسم می‌شود؛ کارت حافظه و فایل تصویر لازم نیست.
این بازطراحی برنامه‌ای تصویر است، نه نمایش پیکسل‌به‌پیکسل PNG.
دهان فعلاً ثابت است؛ تاچ، صدا و همگام‌سازی لب پیاده‌سازی نشده‌اند.

## راه‌اندازی
1. پشتیبانی esp32 از Espressif را در Arduino IDE نصب کنید.
2. کتابخانه TFT_eSPI از Bodmer را نصب کنید.
3. پوشه MimoFace را استخراج کرده و MimoFace.ino را باز کنید.
4. تنظیمات TFT_eSPI را برای مدل دقیق برد تکمیل کنید (پایین).
5. برد مناسب ESP32-S3 و پورت را انتخاب و برنامه را آپلود کنید.
   تنظیمات Flash و PSRAM را از مشخصات واقعی برد بگیرید، نه حدس.

## تنظیمات سخت‌افزار ES3C28P (تکمیل‌شده)
تنظیمات نمایشگر در فایل `tft_setup.h` کنار اسکچ است. TFT_eSPI نسخهٔ 2.5.x این فایل را
خودکار از پوشهٔ اسکچ می‌خواند؛ نیازی به ویرایش User_Setup کتابخانه نیست.
منبع پایه‌ها: جدول «ESP32 Pin Parameters» در صفحهٔ LCDWiki همین برد
(https://www.lcdwiki.com/2.8inch_ESP32-S3_Display).

| سیگنال | GPIO | توضیح |
|---|---|---|
| باس | SPI چهارسیمه | ILI9341V |
| SCLK | 12 | |
| MOSI | 11 | |
| MISO | 13 | |
| CS | 10 | فعال با سطح پایین |
| DC | 46 | بالا = داده، پایین = فرمان |
| RST | ندارد (-1) | به پایهٔ EN (ریست) خود ESP32-S3 وصل است |
| نور پس‌زمینه | 45 | سطح بالا = روشن |

- پنل IPS است: `TFT_INVERSION_ON` و ترتیب رنگ `TFT_RGB`.
- سرعت SPI ۴۰ مگاهرتز (روی همین برد با فریمور XiaoZhi تست شده).
- `USE_HSPI_PORT`: روی ESP32-S3 با Arduino-ESP32 3.x پورت پیش‌فرض FSPI در
  TFT_eSPI باعث کرش موقع init می‌شود.

### تنظیمات برد در Arduino IDE
- Board: **ESP32S3 Dev Module**
- Flash Size: **16MB**
- PSRAM: **OPI PSRAM** (حافظهٔ ۸ مگابایتی داخل تراشه؛ برای Sprite تمام‌صفحه لازم است)
- USB CDC On Boot: **Enabled** (پورت USB-C مستقیم به USB داخلی ESP32-S3 وصل است)

با arduino-cli:

    arduino-cli compile --fqbn esp32:esp32:esp32s3:FlashSize=16M,PSRAM=opi,CDCOnBoot=cdc MimoFace

## کار لازم برای Claude یا توسعه‌دهندهٔ بعدی (انجام شد، بالا را ببینید)
مشخصات قابل‌مشاهده در عکس‌ها:
- برچسب ES3C28P / ESP32-S3_2.8inch
- نمایشگر IPS با وضوح 240×320 و درایور ILI9341
- تاچ خازنی، USB-C، اسلات کارت، خروجی بلندگو
- پایه‌بندی LCD، نوع باس، پایه و سطح فعال نور پس‌زمینه هنوز تأیید نشده است.

ابتدا مستندات یا کد نمونهٔ همین SKU و نسخه سخت‌افزار را پیدا کنید.
این برنامه از TFT_eSPI استفاده می‌کند و به پشتیبانی این کتابخانه از باس
واقعی نمایشگر وابسته است. اگر نمونه سازنده باس/کتابخانه دیگری دارد،
لایه نمایش را تطبیق دهید؛ هیچ GPIOای در این پروژه حدس زده نشده است.

در حالت تأیید SPI بودن نمایشگر، یک Setup اختصاصی در کتابخانه TFT_eSPI
بسازید و از User_Setup_Select.h انتخاب کنید. تنظیمات لازم معمولاً:

    #define USER_SETUP_ID 280
    #define ILI9341_DRIVER
    #define TFT_MOSI <verified GPIO>
    #define TFT_SCLK <verified GPIO>
    #define TFT_CS   <verified GPIO or documented unused value>
    #define TFT_DC   <verified GPIO>
    #define TFT_RST  <verified GPIO or documented reset arrangement>
    // TFT_MISO: set only if wired/needed; otherwise use library's documented setting.
    #define LOAD_GLCD
    #define LOAD_FONT2
    #define SPI_FREQUENCY 20000000

این متن قالب توضیحی است و با placeholderها قابل کامپایل نیست.
فرکانس 20MHz صرفاً نقطه شروع پیشنهادی است و باید با سخت‌افزار تأیید شود.
Setup پیش‌فرض نمایشگر دیگری را هم‌زمان فعال نگذارید.
قرار دادن این defineها فقط در ابتدای ino کافی نیست؛ سورس کتابخانه هم
باید همان تنظیمات را ببیند (Setup کتابخانه یا build flags سراسری).

نور پس‌زمینه را در Setup کتابخانه با TFT_BL و TFT_BACKLIGHT_ON تنظیم کنید،
یا BACKLIGHT_PIN و BACKLIGHT_ON ابتدای اسکچ را تکمیل کنید؛ از دو تنظیم
متناقض استفاده نکنید. مقدار -1 فعلی یعنی اسکچ پایه‌ای را کنترل نمی‌کند.
اگر برد برای تغذیه LCD به GPIO یا تراشه جانبی نیاز دارد، راه‌اندازی آن
را طبق نمونه سازنده، پیش از tft.init() اضافه کنید.

## عیب‌یابی
- صفحه تاریک: ابتدا تغذیه و بک‌لایت را بررسی کنید.
- صفحه روشن اما بدون تصویر: درایور، باس و پایه‌های LCD را بررسی کنید.
- رنگ معکوس یا جابه‌جا: تنظیم RGB/BGR یا inversion متناسب پنل را بررسی کنید.
- تصویر وارونه: setRotation(0) را به setRotation(2) تغییر دهید.
- خطای Sprite: بافر 16 بیتی 153600 بایت حافظه پیوسته می‌خواهد؛
  حافظه آزاد و پیکربندی واقعی PSRAM را بررسی کنید.
- هیچ‌یک از پایه‌های تاچ، باتری و بلندگو در این کد استفاده نمی‌شوند.
